# C/ Game Art

Курс и витрина арт-игр: десять уроков о художниках, работающих через механику игры
(Кори Арканджел, JODI, Джейсон Рорер, Tale of Tales, Molleindustria, Пиппин Барр,
Ed Key & David Kanaga, Дэвид О'Райли, Simogo, Kikiyama).

Каждый урок заканчивается играбельным веб-оммажем работы — чистый HTML/CSS/JS,
без сборки и зависимостей.

## Структура

- `index.html` — лендинг проекта
- `course.html` — курс: 10 уроков с фактами и играми
- `arcade.html` — витрина всех работ с живыми превью
- `assets/` — стили, данные курса, игровой движок

## Запуск

Статический сайт: открыть `index.html` или задеплоить любым статическим хостингом
(GitHub Pages, Netlify, Render Static).
